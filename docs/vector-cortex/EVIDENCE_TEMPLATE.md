# Sprint Evidence Template

Create one durable record at `docs/vector-cortex/evidence/<SPRINT>.md` only when that sprint executes; do not precreate empty records.

```md
# <SPRINT> Evidence
Status: draft | implementer-complete | reviewer-accepted | rejected
Implementation commits/sub-sprint gates: ...
Contract review: reviewer, date, decision, links
Changed production/tests/docs: ...
Fixtures and corpus digests: ...
Migration: ID or "pure sprint—no migration"; counts/ranges/digests/resume/rollback
A/B/C and independence evidence: ...
Commands and verbatim summaries: ...
Evaluation: samples, events, duration, CI, thresholds
Dashboard/API/config/SETTINGS evidence: ...
Offline/network/asset/platform evidence: ...
File sizes and baseline exceptions: ...
Rollback/downgrade rehearsal: ...
Residual risks: ...
Reviewer attestation: name/date/status; acceptance checklist deltas
```

Implementer may set `implementer-complete`; only an independent reviewer sets `reviewer-accepted` and updates README/SPRINT_PLAN status. Evidence must name exact commands and failures; links to ephemeral logs are insufficient without a durable summary.
