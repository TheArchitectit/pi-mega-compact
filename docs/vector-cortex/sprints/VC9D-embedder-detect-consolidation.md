## Failure triad and independence

A cache-hit projection: with the flag on, a memoized detect run with an unchanged key returns the identical cached result and does NOT re-run the expensive compute (pinned by fixture 030); B cache-miss/invalidation projection: a key change (binary path + mtime mutation) forces a recompute producing the fresh result (fixture 031); C the offset (flag-off) VC9C-era behavior: `MEGACOMPACT_VC9D=0` restores per-request fresh spawn, byte-identical to VC9C (fixture 032). A is produced by the memo slot's key-equality short-circuit; B by the key-then-compute ordering in `withDetectMemo`; C purely by the flag branch. All three use independent inputs (the slot state / the injected key / the flag). The dual-sub-tab surface (embedder + cortex present simultaneously in SUB_TABS) is pinned by fixture 033. Common cooldown/spool/restart/clock rules are normative in [TRIAD_RESILIENCE](../TRIAD_RESILIENCE.md).
