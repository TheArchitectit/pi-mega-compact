B artifacts-module constants pin: the fixture reflects the npm-registry tarball URL + sha256 for each of the five `EncoderPlatform` rows exactly as authored in `native-install-artifacts.ts` — pinned by **ENC-INSTALL-002** (constants-present) and **ENC-INSTALL-003** (sha256 format pin: lowercase hex, 64 chars). C absence semantics: when opt-in off OR platform darwin-x64 (the ENC-0e demotion sentinel), the GET omits `nativeOrtInstallGuide` entirely (the ENC-0e demotion reason surfaces in the blockers row INSTEAD) — pinned by **ENC-INSTALL-004** (darwin-x64 guide absent, sentinel intact) and **ENC-INSTALL-005** (flag-off guide absent byte-identical). Contract additivity pinned by **ENC-INSTALL-006**.
