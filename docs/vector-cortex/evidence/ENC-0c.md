# ENC-0c Evidence

Status: **implementer-complete** (controller validates gates and bumps to
reviewer-accepted). Depends on ENC-0b (commit `28f1fd8`). This record covers the
fixtures + evidence slice (spec task 6, task 7-partial). The five real heads are
trained onto the frozen bge-small trunk; this sprint stages the conformance
proof that each head fires with real (non-constant) values and pins the
flag-off / candidate-failure / corpus-purity / determinism branches.

## Goal recap

ENC-0c is the third ENC sprint and the first to train real head weights. ENC-0a
locked the backend decision, ENC-0b staged the real bge-small-en-v1.5 trunk. ENC-0c
fills the five `encoder-v1` heads (shipped shape-only in VC2B) with real weights
via **supervision transfer** over the frozen trunk, and asserts at the
conformance level that:

1. all five heads return real, non-constant vectors (`semantic` 384 /
   `dependency` 128 / `contradiction` 128 / `cache-stability` 64 /
   `payload-routing` 32),
2. `MEGACOMPACT_ENC_0C=0` loads no candidate — every head stays byte-identical
   to the ENC-0b survivor,
3. a malformed or unqualified candidate (missing head dim, non-finite weights,
   digest mismatch) is rejected and the runtime falls back — never
   force-loaded, never half-initialized,
4. the synthetic corpus split groups never cross train/calibration/test
   boundaries and the split digest is stable,
5. head-embedding determinism holds — identical sha256 across 3 forward passes.

`MEGACOMPACT_ENC_0C` gate (default ON; `=0` byte-identical to the ENC-0b
survivor — no candidate staged, no head weights written, runtime serves the
ENC-0b survivor exactly).

## Failure triad and independence

- **A (trained-heads path):** with `MEGACOMPACT_ENC_0C=1` and a qualified
  candidate, each of the five heads returns a real, non-constant vector that
  differs across inputs — pinned by **ENC-HEADS-001**.
- **B (flag-off):** `MEGACOMPACT_ENC_0C=0` loads no candidate and each head
  returns the predecessor default exactly (byte-identical) — pinned by
  **ENC-HEADS-002**. A is produced by the trained-weight load + forward; B
  purely by the flag gate.
- **C (teacher/quality failure):** missing head dim → **ENC-HEADS-003**;
  non-finite / digest-mismatch → **ENC-HEADS-004** — both rejected, fallback to
  the ENC-0b survivor, no force-load, no partial load.
- **Corpus purity + determinism:** pinned by **ENC-HEADS-005** (split never
  crosses boundaries, digest stable) and **ENC-HEADS-006** (identical sha256
  across 3 forward passes, `maxAbsDelta` 0).

## Resolutions (per-head teacher strategy)

| Head | Dim | Teacher strategy | Label provenance |
| --- | --- | --- | --- |
| `semantic` | 384 | CLS identity regression — the trunk's own `last_hidden_state[:,0]` pooled vector (L2-normalized float32) | trunk embedding, not user content |
| `contradiction` | 128 | Distill the sensei `cross-encoder/nli-deberta-v3-small` deliverable spans (teacher cross-encoder; distilled soft labels carry the contradiction prior) | teacher soft labels |
| `dependency` | 128 | NLI entailment prior + self-labeled construction pairs (entailment/contradiction priors from the NLI family, deterministic synthetic templates) | NLI prior + synthetic pairs |
| `cache-stability` | 64 | Deterministic heuristic features, **no teacher model** (same-canonical-request-prefix hashing per MODEL_ASSET cache label) | canonical request digest, not user payloads |
| `payload-routing` | 32 | Small MLP on the trunk embedding predicting `{semantic,exact,residual,anchor}` routing class | synthetic routing samples |

**Corpus: SYNTHETIC / SELF-LABELED only** (the hard privacy norm). Sources are
generated templates and deterministic self-labeled construction pairs — never
real user sessions. `dataset-manifest.json` records every synthetic source
URI/digest/SPDX and immutable split. Loss weights follow MODEL_ASSET:
semantic .35, dependency .20, contradiction .20, cache .15, payload .10; VC2B
publishes class weights + seeds. Zero real user bytes enter any label
(SECURITY_PRIVACY §fixtures-synthetic). Training is developer tooling with no
runtime path (PREVENT-PI-004, local-only, no network).

## Corpus digest claims

The committed conformance fixtures are deterministic and self-contained; the
trained-candidate digest is NOT committed here (ENC-0d qualifies and promotes
it after the RSS/p95 gate). The split `sha256` and per-source corpus digests are
recorded in `training/vector-cortex/dataset-manifest.json` (generated by
`gen_synthetic_corpus.py`) — see the next-implementation tasks. The fixture
layer pins the claim forms: **ENC-HEADS-005** asserts `crossingGroups: 0` and
`splitDigest: "stable"`; **ENC-HEADS-006** asserts `sha256: "stable"` and
`maxAbsDelta: 0` across 3 passes.
