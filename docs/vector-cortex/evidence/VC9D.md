## Evaluation

- The detect cache is READ-ONLY: `/api/setup-detect` returns installed/models/detail aggregates only, never payload bytes/prompts/ledger (EVAL-REDACT-002); detection performs only local binary spawns + filesystem stat (PREVENT-PI-004, each decoration line carries a guardrails-allow annotation).
- Memoization matches the `healthFactCacheKey` invalidation pattern: the cache key includes the mutable input (resolved binary path + size/mtime; onnx module path + mtime), so an install/upgrade on PATH or in node_modules naturally invalidates while a steady environment reuses the result instead of re-spawning the expensive `ollama --version`/`ollama list`.
- `MEGACOMPACT_VC9D=0` is byte-identical to the VC9C-era behavior: the handler branches to the raw fresh detectors (per-request spawn), the shared module-level memo slot is never consulted, and the embedder sub-tab's new 5s cadence is the only additive client change (the Cortex sub-tab surface is unchanged by VC9D — both remain present, pinned by fixture 033).

## Offline/network/asset/platform evidence

Platform-neutral — the memoized wrappers key on whatever `which`/`stat`/`resolve` reports for the running host.
